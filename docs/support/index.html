OptiUniverse Support

For help with OptiUniverse Release 1, use the GitHub issue tracker. Include your device model, iOS version, app version, and a short description of what happened.

Open a Support Issue View Known Issues

What to include

A complete report makes it easier to reproduce and fix issues quickly.

  1. Device model, such as iPhone 17 Pro or iPad Pro.
  2. iOS or iPadOS version.
  3. OptiUniverse app version.
  4. Steps to reproduce the issue.
  5. Screenshots or a screen recording when they help explain the problem.

Rendering or performance

Report blank screens, visual artifacts, slow rendering, camera-control problems, or issues with planet and orbit visuals.

Content corrections

Report incorrect object facts, missing attribution, unclear descriptions, or metadata that should be updated.
