Built for space exploration

Real-time discovery on iPhone and iPad.

OptiUniverse combines a SwiftUI discovery interface with a MetalKit scene for browsing celestial destinations, following worlds, and inspecting orbital details.

Metal rendering

HDR rendering, bloom, tone mapping, textured materials, and a star-field backdrop create a detailed real-time space scene.

Solar-system guide

Destination cards surface key facts including distance, diameter, orbital period, temperature, and concise descriptions.

Interactive navigation

Pan, pinch, rotate, follow celestial objects, and visualize transfer-orbit routes for supported destinations.
